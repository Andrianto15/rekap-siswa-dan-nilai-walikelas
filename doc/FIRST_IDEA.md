aplikasi rekap kehadiran dan nilai untuk guru wali kelas

# rekap kehadiran (menu guru)

- ada menu input kehadiran per siswa per tanggal
- ada menu untuk input kehadiran per siswa per bulan
- ada rekap per bulan dan keseluruhan
- ada rekap per siswa juga (berapa sakit, ijin, alfa)
- rekap per siswa bisa juga dilihat per bulan, jadi keliatan siswa A bulan A B C rekap kehadiran nya
- view rekap bisa dalam bentuk table saja supaya semua siswa keliatan jangan per siswa
- bisa download dalam bentuk excel hasil rekap nya

# rekap nilai (menu guru)

- bisa input nilai per siswa
- bisa input maksimal 5 nilai
- bisa rekap nilai (rata-rata) dari jumlah nilai yg ada, misal ada 3 nilai berarti rata-rata dari 3 nilai, kalo ada 5 berarti rata-rata dari 5 nilai
- bisa download dalam bentuk excel hasil rekapnya
- ada menu untuk lihat nilai akhir (hasil rata") dan bisa di edit
- bisa liat urutan ranking dari 1 sampai terakhir berdasarkan nilai akhir

# general

- ada fitur login
- ada role admin dan guru
- ada menu admin untuk mapping guru dan mata pelajaran
- ada menu admin mapping user
- ada menu guru untuk input siswa satu per satu atau dengan upload file excel
- ada halaman dashoard di role guru untuk liat summary kehadiran per bulan (berapa sakit, ijin, alfa), total siswa
- guru hanya bisa akses menu guru, admin bisa akses menu guru dengan view yang lebih luas, bisa pilih guru dan mapel nya
- user di beri akses oleh admin, tidak bisa register sendiri
